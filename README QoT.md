# PON QoT Dataset Analysis

Jupyter notebooks supporting the paper:

> **An Experimental Dataset for Machine Learning-Based QoT Assessment in Optical Access Networks**
> Berenice Arguero, Christian Tipantuña, Germán V. Arévalo — *IEEE Access*

This repository contains the code used to audit the dataset, train and evaluate the machine learning models, and generate the figures and tables reported in the manuscript.

## About the dataset

The dataset contains **6,065 observations** from two controlled laboratory campaigns in optical access networks (PON):

- **PRBS-NRZ**
- **LTE-QPSK**

It includes experimental configuration variables, receiver-side telemetry, QoT indicators (BER, EVM, Q-factor), KPI provenance, campaign-specific QoT labels (*Excellent*, *Acceptable*, *Degraded*), and a fixed group-aware train/test split to prevent information leakage.

📦 **Download:** IEEE DataPort — [https://doi.org/10.21227/xjrn-d571](https://doi.org/10.21227/xjrn-d571)

The dataset file (`Dataset_Publication_v1.0.xlsx`) is **not** included in this repository. Download it from IEEE DataPort and place it in the repository root.

## Notebooks

### `01_dataset_ml_validation.ipynb`

End-to-end validation and machine learning workflow:

| Activities | Content |
|---|---|
| 1–3 | Dataset loading, structural audit, KPI provenance audit, validation of the frozen group-based train/test split |
| 4–7 | Predictor sets (*Configuration* and *Telemetry*), target-leakage prevention, preprocessing pipeline, baselines, group-aware cross-validation |
| 8–10 | Benchmark of Gradient Boosting, Random Forest, SVM, and MLP; hyperparameter optimization; independent test evaluation |
| 11–14 | Group-level bootstrap confidence intervals, permutation feature importance, publication figures and tables |
| 15–21 | Robustness, failure-region analysis, learning curves, cross-model agreement, pairwise statistical comparison, final benchmark synthesis |

### `02_descriptive_analysis.ipynb`

Descriptive analysis reported in the manuscript:

- QoT class distribution by campaign
- Statistical characterization of experimental variables
- Kruskal–Wallis tests with ε² effect size and Holm correction
- Pairwise Mann–Whitney U post-hoc tests with rank-biserial correlation
- PCA and UMAP visualizations of QoT separability
- Classification difficulty of the *Acceptable* class

## Main results

| Campaign | Best scenario | Max. Macro-F1 |
|---|---|---|
| LTE-QPSK | Configuration | 0.910 |
| PRBS-NRZ | Telemetry | 0.789 |

The most relevant predictors were modulator bias voltage, VOA attenuation, transmission rate, received optical power, and SOA current.

## How to run

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-username>/pon-qot-dataset-analysis.git
   cd pon-qot-dataset-analysis
   ```

2. Install the dependencies (Python 3.10 or later):

   ```bash
   pip install -r requirements.txt
   ```

3. Download `Dataset_Publication_v1.0.xlsx` from [IEEE DataPort](https://doi.org/10.21227/xjrn-d571) and place it in the repository root.

4. Run the notebooks **in order**:

   ```bash
   jupyter notebook
   ```

   - First `01_dataset_ml_validation.ipynb`
   - Then `02_descriptive_analysis.ipynb` (it uses tables generated by notebook 01, such as `tables/table_main_benchmark_manuscript.csv`)
